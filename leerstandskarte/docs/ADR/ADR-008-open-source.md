# ADR-008: Open Source (MIT)

**Datum:** 2026-05-08  
**Status:** Akzeptiert

## Entscheidung

Veröffentlichung unter **MIT-Lizenz**.

## Begründung

Kein kommerzielles Interesse; maximale Weitergabe und Wiederverwendung durch andere Verbände ist erwünscht; das FOSS-Prinzip des Projekts wird konsequent umgesetzt.

## Konsequenz

Der Code wird öffentlich auf einer Plattform wie Codeberg oder GitHub veröffentlicht, sobald die finale Version steht.
